# Merhy Engenharia — demonstrativo

Prévia online: [https://willy-azevedo.github.io/merhy-engenharia-demo/](https://willy-azevedo.github.io/merhy-engenharia-demo/)

Página inicial para avaliação de composição, conteúdo e interações. A implementação no WordPress e as páginas internas pertencem à próxima etapa.

O formulário demonstra a interface; o contato está disponível pelos links de WhatsApp, telefone e e-mail.

## Publicação

GitHub Pages publica a raiz da branch `main`. Os arquivos usam caminhos relativos, compatíveis com o endereço do projeto.
